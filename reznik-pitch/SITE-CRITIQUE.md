# What’s wrong with the current carywills.com

Tone for calls and email: factual and respectful. Frame as “the site undersells the firm,” not “your site is bad.”

## Quick pointers (use 3–5 in conversation)

1. **DIY platform feel** — Built on Wix. Fine for a starter site, weak for a board-certified estate planning practice.
2. **Trust mismatch** — Credentials are strong. The first impression does not match that level of professionalism.
3. **Hard to scan** — Long text blocks force families to dig for services, process, and next steps.
4. **Weak hierarchy** — Brand, offer, and “schedule” do not lead the page clearly enough.
5. **CTA friction** — Booking exists, but the path to appointment is easier to miss than it should be.
6. **Specialty not obvious fast enough** — Niche focus (estate planning only) should hit harder in the first few seconds.
7. **Inconsistent polish** — Layout and media feel pieced together rather than one calm system.
8. **Mobile clarity** — Dense sections get heavier on phones, where many clients will look first.
9. **Competes on content, not confidence** — Lots of information, not enough quiet authority.
10. **Opportunity** — Same logo, same facts, stronger structure would make the firm look as trusted as the work already is.

## Fuller notes for the pitch call

| Area | Current issue | What a redesign fixes |
|---|---|---|
| First impression | Template / builder energy | Calm brand-led homepage |
| Copy layout | Walls of text | Short sections, clearer next step |
| Navigation | Easy to get lost in content | Multi-page IA that matches how clients decide |
| Scheduling | Present but not dominant | Clear schedule path on every key page |
| Visual system | Uneven spacing and hierarchy | One consistent design system |
| Differentiation | Specialty buried in paragraphs | “Estate-only boutique” shown up front |
