# Reznik Law redesign (concept)

This is the improved **Reznik Law / carywills.com** concept site.

It is **not** the Brandon Fonville studio homepage.

## Open / preview

```bash
cd ~/Projects/reznik-law-redesign
python3 -m http.server 5174
```

Then open: http://127.0.0.1:5174/

## Files

- `index.html` — homepage
- `styles.css` — design
- `app.js` — nav + motion
- other `*.html` pages
- `assets/` — logo, hero, attorney photos
